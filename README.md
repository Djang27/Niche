# Niche

A Roblox party game where you answer prompts like "Name a country in Africa" and score more for rarer answers.
Common 10, Rare 30, Super Rare 60, Epic 80, Legendary 100.

## Dev setup

1. Install Rokit, then from this folder: `rokit add rojo-rbx/rojo` and `rojo plugin install`
2. `rojo serve`
3. In Roblox Studio: Plugins tab > Rojo > Connect
4. Edit files in `src/`, Studio updates live

Publish from Studio with File > Publish to Roblox.
